# 🍳 CookBook Digital

A modern, full-stack recipe management application built with React, Node.js, Express, and MongoDB. Discover, create, and manage your favorite recipes with a beautiful, responsive interface.

![React](https://img.shields.io/badge/React-18.2.0-blue)
![Node.js](https://img.shields.io/badge/Node.js-Express-green)
![MongoDB](https://img.shields.io/badge/MongoDB-Database-green)
![Responsive](https://img.shields.io/badge/Design-Responsive-orange)

## ✨ Features

### 🎨 User Experience
- **Responsive Design** - Perfect experience on desktop, tablet, and mobile
- **Modern UI/UX** - Beautiful orange/black theme with smooth animations
- **Intuitive Navigation** - Easy-to-use interface for all skill levels

### 📝 Recipe Management
- **Add New Recipes** - Complete form with ingredients, instructions, and images
- **Smart Search** - Real-time search across titles, descriptions, and ingredients
- **Edit & Update** - Modify existing recipes with ease
- **Delete Recipes** - Remove recipes you no longer need

### 🔧 Technical Features
- **Full CRUD Operations** - Create, Read, Update, Delete functionality
- **RESTful API** - Clean backend architecture
- **Database Integration** - MongoDB with Mongoose ODM
- **Error Handling** - Graceful error management and user feedback

## 🛠️ Tech Stack

### Frontend
- **React 18** - Modern React with hooks
- **Axios** - HTTP client for API calls
- **CSS3** - Custom responsive styling
- **Component-Based Architecture** - Reusable and maintainable code

### Backend
- **Node.js** - Runtime environment
- **Express.js** - Web application framework
- **MongoDB** - NoSQL database
- **Mongoose** - MongoDB object modeling
- **CORS** - Cross-origin resource sharing
