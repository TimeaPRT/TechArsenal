# Word Frequency Analyzer

A simple Python CLI (Command Line Interface) tool that analyzes the frequency of words in a text or text file.  
This project is designed for **beginners learning Python**, focusing on functions, lists, dictionaries, file I/O, and basic text processing.

## Features

- Read text from user input or a file (`input.txt`)
- Preprocess text: lowercase, remove punctuation, filter stopwords
- Count word frequency
- Display results in the terminal
- Save results to `results.txt`
- Display summary statistics:
  - Total words
  - Unique words
  - Most frequent word
- Beginner-friendly code, fully in Python
