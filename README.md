# Real-Time Emotion Detector

A **Python project** that detects human emotions in real time using your **webcam**, powered by **OpenCV** and **DeepFace**.  
The program recognizes emotions on your face and displays them on the video feed with confidence percentages.

## Features

- Real-time emotion detection via webcam
- Recognizes multiple emotions (happy, sad, angry, surprise, etc.)
- Displays **dominant emotion** and confidence percentage on screen
- Draws rectangles around detected faces
- Simple **CLI interface**
- Press `'q'` to quit the application

## Tech Stack

- **Language:** Python 3.x  
- **Libraries:** OpenCV (`cv2`), DeepFace  
- **Computer Vision:** Real-time face detection and emotion recognition
