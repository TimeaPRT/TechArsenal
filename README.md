# Password Generator

A simple Python project that generates secure random passwords and allows you to save them to a file.  

## Features

- Generate strong random passwords with letters, numbers, and symbols.
- Save generated passwords to a file for later use.
- Easy to run and customize.

## Requirements

- Python 3.x

## How to Use

1. Clone the repository or download the `password_generator.py` file.
2. Run the script using Python:

```bash
python password_generator.py
