# 2FA Authentication System

A modern **full-stack authentication system** built with **React**, **Node.js**, and **MongoDB**, featuring **Two-Factor Authentication (2FA)** for enhanced security.  
Includes a **modern UI**, verification codes, a **Dashboard**, and a seamless login/signup flow.

## Features

- **User Registration and Login**
- **Two-Factor Authentication (2FA)** via email or app
- **Secure password hashing** with bcrypt
- **Modern React UI** with responsive design
- **MongoDB database** for user management
- **Backend API** built with Node.js and Express
- **Real-time feedback** for login/signup errors
- **Dashboard** for logged-in users to view their profile or account info
- Easy to extend and integrate with other apps

## Tech Stack

- **Frontend:** React, Tailwind CSS / CSS modules
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Atlas or local)
- **Authentication:** JWT, bcrypt, 2FA verification code
