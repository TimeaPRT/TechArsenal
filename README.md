## 🦇  Gothic Clothing E-Commerce
Dark fashion for the modern soul

A sleek, React-based e-commerce platform specializing in gothic apparel and accessories. Built with modern web technologies and a hauntingly beautiful design.

## ✨ Features
🛍️ Product Catalog - Browse our curated collection of gothic clothing

🎯 Smart Filtering - Find your style with category-based filtering

🛒 Shopping Cart - Seamless add-to-cart and quantity management

🔐 User Authentication - Secure login/signup system

📏 Size Guide - Comprehensive sizing assistance

📱 Responsive Design - Perfect on any device

🌙 Dark Theme - Immersive gothic aesthetic


## 🚀 Tech Stack

React 18 - Modern frontend framework

TypeScript - Type-safe development

Tailwind CSS - Utility-first styling

Vite - Lightning-fast build tool

## ⚡ Quick Start
Get up and running in minutes:

bash
# Clone the repository
git clone https://github.com/yourusername/goth-clothing.git

# Navigate to project directory
cd goth-clothing

# Install dependencies
npm install

# Start development server
npm run dev
Your site will be live at http://localhost:5173 🎉

## 🏗️ Build for Production
bash
# Create production build
npm run build

# Preview production build locally
npm run preview
